# 网页剪藏:书签安装与排障(给模型引导用户用)

内网网页需要登录,导入环境访问不到。管理员在**已登录的浏览器**里点书签「导入知识库」,书签把页面正文与页内图片交给剪藏页,
剪藏页存进导入环境并自动发起导入。这份说明是你一步一步带用户操作时的依据:**每步说一件事,等用户回「好了」再说下一步**。

安装页链接以 `kb.py clip status` 的输出为准(形如 `/kb-import/clip/install`),**原样贴给用户,不要自己拼地址**。
书签代码由安装页按本系统地址生成;**你不要写、改或解释任何 `javascript:` 代码**。

## 1. 安装(按浏览器)

### Chrome

1. 显示书签栏:按 **Ctrl+Shift+B**(Mac 上 **Cmd+Shift+B**),地址栏下方出现一条书签栏。
2. 点我给的安装页链接,打开安装页。
3. 用鼠标按住页面上蓝色的「导入知识库」按钮,拖到书签栏上松开。书签栏里出现「导入知识库」就装好了。
4. 拖不动(公司策略禁止拖拽):点安装页上的「复制书签代码」→ 按 **Ctrl+Shift+O** 打开书签管理器 → 右上角 ⋮ →「添加新书签」→
   名称写「导入知识库」,网址粘贴刚才复制的内容 → 保存,再把它拖到书签栏。

### Microsoft Edge

1. 显示收藏夹栏:按 **Ctrl+Shift+B**(Mac 上 **Cmd+Shift+B**)。
2. 打开安装页,把「导入知识库」按钮拖到收藏夹栏。
3. 拖不动:点「复制书签代码」→ **Ctrl+Shift+O** 打开收藏夹 →「添加收藏夹」→ 名称「导入知识库」,URL 粘贴 → 保存到「收藏夹栏」。

### 360 安全浏览器 / 奇安信可信浏览器

1. **先确认是「极速模式」**:地址栏右侧有闪电图标(极速)和 e 图标(兼容)。兼容模式(IE 内核)下书签剪藏用不了,点闪电切到极速模式。
2. 显示收藏栏:菜单 →「收藏」→「显示收藏栏」(或 Ctrl+Shift+B)。
3. 打开安装页,把「导入知识库」拖到收藏栏;拖不动就「复制书签代码」→ 收藏栏上右键 →「添加网页」→ 名称「导入知识库」、网址粘贴。

### Firefox

1. 显示书签工具栏:**Ctrl+Shift+B**(Mac 上 **Cmd+Shift+B**)。
2. 打开安装页,把「导入知识库」拖到书签工具栏。
3. 拖不动:「复制书签代码」→ 书签工具栏上右键 →「添加书签」→ 名称「导入知识库」、网址粘贴 → 保存。

## 2. 使用

1. 在浏览器里打开要导入的那一页,**确认已经登录、内容已经加载完**(折叠的内容展开也可以,书签取的是当前页面)。
2. 点书签栏上的「导入知识库」。会弹出一个小窗口(剪藏页),显示标题、来源、正文字数、图片数。
3. 核对无误点「导入」。剪藏页会存好材料,并自动在导入环境新开一个会话开始整理;窗口里有「打开导入会话」的链接。
4. 多个页面:逐页打开、逐页点书签;最后在导入环境里说「导入刚才剪藏的几页」。

## 3. 排障

| 现象 | 原因 | 怎么处理 |
|---|---|---|
| 点了书签没反应 | 浏览器拦截了弹窗 | 地址栏右侧出现「已拦截弹窗」图标,点它选「始终允许」,再点一次书签 |
| 允许弹窗后仍没反应 | 这个网站的安全策略拦住了书签脚本 | 用第 4 节的 .mhtml 退路 |
| 剪藏页提示「来源网站不在允许名单」 | 平台没把这个网站加进 `KB_CLIP_ORIGINS` | 请平台在 agent-config 里加上,改完重启网关与导入环境 |
| 剪藏页提示「请从要导入的网页上点书签打开本页」 | 直接打开了剪藏页 | 回到要导入的网页点书签;或按第 4 节把 .mhtml 拖进剪藏页 |
| 导入时提示「剪到的是登录页」 | 页面没登录,或登录已过期 | 刷新页面、重新登录后再点书签 |
| 提示「抽不到正文」 | 正文在内嵌框架里,或页面还没加载完 | 等加载完再点;正文在框架里时,打开框架本身的地址再剪;仍不行用 .mhtml |
| 有图片「没取回」 | 跨站图片(CDN、别的系统)浏览器不让读 | 需要的截图另存为图片,上传到收件目录 |
| 书签打开的是旧地址 | 系统换了地址 | 删掉旧书签,重新打开安装页装一次 |
| 提示「您不是知识库管理员」 | 账号没有知识库管理员角色 | 请平台在统一认证的角色或 agent-roles 里登记 |

## 4. 退路:另存为网页文件上传

1. 在要导入的页面按 **Ctrl+S**(Mac **Cmd+S**),保存类型选「网页,单个文件(*.mhtml)」,保存到桌面。
2. 打开剪藏页(安装页上有「打开剪藏页」的链接),把刚才的 .mhtml 文件拖进页面的虚线框里,点「导入」。
3. 之后与书签剪藏完全一样。只存了「网页,仅 HTML」的 .html 文件也能拖进去,只是图片不在里面。
4. 没有剪藏页(单机版、或平台没开剪藏):请用户把 .mhtml 通过对话界面上传到收件目录,你执行
   `kb.py clip add <沙箱内路径>`(文件里没记原网页地址时加 `--url <地址>`),再按 SKILL.md「网页剪藏」第 4 步起处理。
